# Hotel Booking Cancellation Prediction

## Project Overview

This project predicts whether a hotel booking will be cancelled or not using Machine Learning.

An **XGBoost Classifier** is used to predict booking cancellations based on customer and booking-related details.

The project includes a Streamlit frontend and a FastAPI backend to provide real-time predictions.

## How to Run the Project Locally

### 1. Clone the Repository

```bash
git clone https://github.com/ChennuPeshmaDeviSree/Hotel-Booking-Cancellation-Prediction.git
```

### 2. Navigate to the Project Folder

```bash
cd Hotel-Booking-Cancellation-Prediction
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Download the Dataset

Download the Hotel Booking Demand dataset from Kaggle:

https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand

Place the downloaded `hotel_bookings.csv` file in the project folder.

### 5. Train the Model

Run the following command:

```bash
python train.py
```

This performs data preprocessing, trains and tunes the XGBoost model, evaluates its performance, and generates the `hotel_booking_xgboost.pkl` file.

### 6. Run the FastAPI Backend

Open a terminal and execute:

```bash
python -m uvicorn app:app --reload --port 8000
```

The FastAPI backend will run at:

http://127.0.0.1:8000

API documentation:

http://127.0.0.1:8000/docs

### 7. Run the Streamlit Frontend

Open another terminal and execute:

```bash
python -m streamlit run streamlit_app.py
```

The Streamlit application will open in your browser.

## Application Features

- Enter hotel booking details.
- Predict whether a booking will be cancelled.
- Display cancellation probability.
- Interactive Streamlit user interface.
- FastAPI-based prediction backend.
- Machine Learning-based predictions using XGBoost.

## Deployment

The application is deployed using the following platforms:

- **Frontend:** Streamlit Community Cloud
- **Backend:** Render
- **API:** FastAPI

The Streamlit frontend sends booking details to the deployed FastAPI backend. The backend uses the trained XGBoost model to generate predictions and return the cancellation probability.

## Model Details

- **Algorithm:** XGBoost Classifier
- **Problem Type:** Binary Classification
- **Target Variable:** `is_canceled`
- **0:** Not Cancelled
- **1:** Cancelled
- **Model File:** `hotel_booking_xgboost.pkl`
